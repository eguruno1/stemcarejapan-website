# Phase 0: 프로젝트 기초 세팅 개발계획서 — 완료

작성일: 2026-09-04 · 구현 검토 및 완료일: 2026-09-18

상태: **완료**. npm workspace, 공용 타입, Express API, Next.js 관리자 뼈대, PostgreSQL과 기존 정적 홈페이지의 동시 실행을 확인했다. Phase 1 검토 수정까지 반영한 현재 구현을 기준으로 한다.

기존 단계별 코드 작성 예시는 [검토 전 원문](../history/20260918_phase0-1_review/20260904_phase0_상담채팅시스템개발계획서.md)에 보존했다. 아래 작업 목록이 현재 완료 판정과 구현 기준이며, 과거 코드 예시로 현재 파일을 덮어쓰지 않는다.

## 현재 구조와 공통 제약

- Node.js 22 LTS / npm workspaces / TypeScript 5 / Express 4 / Next.js 15 / PostgreSQL 16.
- API·shared는 CommonJS. **관리자는 Next.js의 esnext/bundler 설정**을 사용한다. 기존의 “모든 TypeScript는 CommonJS” 제약을 정정한다.
- 포트: 홈페이지 8080, 관리자 3100, API 4000, PostgreSQL 호스트 5434 / 컨테이너 5432.
- 허용 목록과 타입은 `packages/shared/src/constants.ts`, `types.ts`를 기준으로 한다. 언어 `ko/ja`, 감지 실패 `unknown`; 서비스 `stemcell/korea_travel/undecided`; 방 상태 `bot/waiting/active/closed`.
- 요청 enum 검증은 shared 상수를 import한다. 현재 서비스·Prisma 스키마의 기본값 및 비교에는 리터럴도 사용한다. “모든 문자열 직접 작성 금지” 대신 허용 목록의 중복 정의를 금지한다.
- API 환경변수는 `src/config.ts`, 관리자 환경변수 로딩은 `next.config.ts`, 클라이언트 접근은 `lib/env.ts`에서 담당한다. seed·테스트·Prisma CLI는 별도 실행 진입점으로 루트 `.env`를 읽는다.
- `.env`와 빌드 산출물은 Git 제외. `docs/`도 현재 Git 제외이므로 계획서는 로컬 문서로 관리한다.
- 구현 소스와 테스트를 현재 기준으로 삼고, 버그 수정에는 회귀 테스트를 추가한다. 과거 RED 실행이나 새 커밋 생성을 완료 판정으로 소급하지 않는다.
