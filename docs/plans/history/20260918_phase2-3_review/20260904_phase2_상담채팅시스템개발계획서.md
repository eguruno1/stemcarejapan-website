**Goal:** 홈페이지 우하단 상담 위젯을 "상담 폼 자동입력 도구"에서 "실제 서버와 연결된 채팅창"으로 바꾼다. 고객이 상담을 시작하고, 메시지를 주고받고, 새로고침해도 대화가 이어진다.

**Architecture:** 현재 `js/chat-widget.js` 한 파일에 뭉쳐 있는 로직을 `js/chat/` 아래 5개 모듈(config·api·state·render·widget)로 나눈다. 빌드 도구가 없는 정적 사이트이므로 **ES module(`<script type="module">`)** 을 그대로 쓴다. 실시간 통신은 Phase 4에서 붙이므로, 이번 Phase는 **3초 폴링**으로 새 메시지를 가져온다. 폴링 코드는 Phase 4에서 통째로 교체할 수 있도록 `poller.js` 한 파일에 격리한다.

**Phase Scope Note:** 구축계획서의 Phase 2에는 Socket.IO 연결 예시가 포함되어 있지만, 개발계획서는 위험을 줄이기 위해 고객 위젯 UI와 REST 연동을 먼저 완성하고 Socket.IO는 Phase 4에서 고객·운영자·서버를 함께 전환한다. 따라서 이 Phase의 "메시지 수신" 완료 기준은 **3초 폴링으로 수신되는 상태**를 뜻하며, 새로고침 없는 진짜 실시간성은 Phase 4 완료 기준에서 검증한다.

**Tech Stack:** Vanilla JavaScript (ES modules, 빌드 없음), Fetch API, localStorage, Playwright(E2E)

## Global Constraints

Phase 0 문서의 **Global Constraints 전체가 그대로 적용된다.** 추가 제약:

- **빌드 도구를 도입하지 않는다.** webpack/vite 없이 브라우저가 바로 읽는 ES module만 쓴다.
- 위젯은 홈페이지 세 페이지(`/`, `/stemcell/`, `/korea-travel/`)에서 모두 동작해야 한다. 루트 페이지는 상담 폼이 없으므로 서비스 선택 링크만 보여준다.
- 기존 `css/style.css`의 `.consult-chat*` 클래스 이름을 **재사용**한다. 새 클래스는 `.consult-chat-` 접두어를 붙여 추가한다.
- 개인정보 동의 체크가 없으면 **API를 호출하지 않는다.** (서버에서도 막지만 화면에서 먼저 막는다)
- `visitorToken`은 `localStorage`에만 저장하고, **콘솔에 출력하지 않는다.**
- 자동 스크롤은 "사용자가 맨 아래를 보고 있을 때만" 한다. 예외 없다.
- 모든 텍스트는 한국어/일본어 두 벌을 갖는다. `getLang()` 결과에 따라 고른다.

## 이 Phase를 시작하기 전에 알아야 할 개념

**왜 폴링을 먼저 만드나?**
"실시간"은 Socket.IO가 필요한데, 그건 서버·고객·운영자 세 곳을 동시에 고쳐야 한다. 지금 그걸 하면 어디가 고장났는지 찾기 어렵다. 먼저 "3초마다 서버에 새 메시지 있냐고 물어보는" 단순한 방식으로 화면을 완성하고, Phase 4에서 그 부분만 갈아끼운다. `poller.js` 하나만 버리면 되도록 설계하는 게 핵심이다.

**낙관적 UI(optimistic UI)란?**
사용자가 전송 버튼을 누르면 서버 응답을 기다리지 않고 **먼저 화면에 말풍선을 띄우는** 방식이다. 서버가 성공을 알려주면 그 말풍선을 진짜 메시지로 확정하고, 실패하면 "전송 실패 · 다시 시도" 표시를 붙인다. 이게 없으면 인터넷이 느릴 때 버튼을 눌러도 아무 반응이 없어 사용자가 여러 번 누른다.

**`clientMessageId`가 왜 필요한가?**
낙관적 UI로 먼저 띄운 임시 말풍선과, 나중에 서버에서 내려온 진짜 메시지가 **같은 것**임을 알아야 중복으로 두 개가 보이지 않는다. 그래서 보내기 전에 브라우저가 고유 ID를 만들어 붙이고, 서버가 그 ID를 그대로 돌려준다. Phase 1에서 DB에 `@@unique([chatRoomId, clientMessageId])`를 걸어둔 이유이기도 하다.

**스크롤 원칙이 왜 중요한가?**
고객이 위로 올려서 이전 안내를 읽는 중인데 새 메시지가 와서 화면이 확 내려가면, 읽던 곳을 잃어버린다. 상담 화면에서 이건 신뢰도 문제다. 그래서 "맨 아래 근처(100px 이내)를 보고 있을 때만 따라가고, 아니면 '새 메시지' 버튼만 띄운다"는 규칙을 지킨다.

```text
    ├── render.js          ★ DOM 생성 + 스크롤 관리
    └── widget.js          ★ 진입점: 이벤트 연결과 흐름 제어

index.html                 ★ script 태그 교체
stemcell/index.html        ★ script 태그 교체
korea-travel/index.html    ★ script 태그 교체

tests/e2e/
├── playwright.config.ts   ★
└── chat-widget.spec.ts    ★
```

**파일별 책임**

| 파일 | 책임 | 다른 파일을 import 하는가 |
|---|---|---|
| `config.js` | 상수만. 로직 없음 | 안 함 |
| `i18n.js` | 문구 사전 + `t(key)` | config |
| `state.js` | 현재 상담방/메시지 보관, 변경 알림 | config |
| `api.js` | HTTP 호출만. DOM을 모른다 | config, state |
| `poller.js` | 주기적 조회. DOM을 모른다 | api, state |
| `render.js` | DOM 생성/갱신만. fetch를 모른다 | i18n, state |
| `widget.js` | 위 전부를 엮는 유일한 곳 | 전부 |

**이 분리가 지켜지는지 확인하는 법**: `render.js`에 `fetch`가 있으면 잘못됐다. `api.js`에 `document`가 있으면 잘못됐다.

- [ ] **Step 4: `js/chat/state.js` 작성**

```js
import { STORAGE_KEY } from './config.js';

/**
 * 위젯의 모든 상태가 여기 모여 있다.
 * 화면(render.js)은 이 상태를 읽기만 하고, 바꾸는 건 widget.js 뿐이다.
 */
const state = {
  session: null,        // { roomId, visitorToken }
  room: null,           // { status, customerName, preferredLanguage, serviceType }
  messages: [],         // 서버가 확정한 메시지 (MessageDTO[])
  pending: [],          // 아직 서버 확인 전인 내 메시지
  phase: 'form',        // 'form' | 'starting' | 'chat' | 'error'
  errorKey: null,       // i18n 키
  connection: 'idle'    // 'idle' | 'ok' | 'reconnecting'
};

const listeners = new Set();

export function subscribe(listener) {
  listeners.add(listener);
  return () => listeners.delete(listener);
}

function notify() {
  for (const listener of listeners) listener(getState());
}

export function getState() {
  // 얕은 복사를 돌려줘서 바깥에서 실수로 원본을 고치지 못하게 한다.
  return { ...state, messages: [...state.messages], pending: [...state.pending] };
}

/* ---------- 세션 (localStorage) ---------- */

export function loadSession() {
  try {
    const raw = window.localStorage.getItem(STORAGE_KEY);
    if (!raw) return null;
    const parsed = JSON.parse(raw);
    if (!parsed?.roomId || !parsed?.visitorToken) return null;
    state.session = parsed;
    return parsed;
  } catch {
    // 사파리 프라이빗 모드 등에서 localStorage 접근이 막힐 수 있다.
    return null;
  }
}

export function saveSession(session) {
  state.session = session;
  try {
    window.localStorage.setItem(STORAGE_KEY, JSON.stringify(session));
  } catch {
    // 저장 실패해도 이번 세션 동안은 메모리로 동작한다.
  }
  notify();
}

export function clearSession() {
  state.session = null;
  state.room = null;
  state.messages = [];
  state.pending = [];
  state.phase = 'form';
  try {
    window.localStorage.removeItem(STORAGE_KEY);
  } catch {
    /* 무시 */
  }
  notify();
}

export function getSession() {
  return state.session;
}

/* ---------- 화면 단계 ---------- */

export function setPhase(phase, errorKey = null) {
  state.phase = phase;
  state.errorKey = errorKey;
  notify();
}

export function setConnection(connection) {
  if (state.connection === connection) return;
  state.connection = connection;
  notify();
}

/* ---------- 상담방과 메시지 ---------- */

export function setRoom(room) {
  state.room = room;
  notify();
}

/**
 * 서버에서 받은 메시지 목록을 병합한다.
 * - 이미 있는 id 는 갱신 (번역이 늦게 붙는 경우)
 * - 같은 clientMessageId 의 pending 은 제거 (중복 표시 방지)
 */
export function upsertMessages(incoming) {
  const byId = new Map(state.messages.map((m) => [m.id, m]));
  for (const message of incoming) {
    byId.set(message.id, message);
  }
  state.messages = [...byId.values()].sort(
    (a, b) => new Date(a.createdAt) - new Date(b.createdAt)
  );

  const confirmedClientIds = new Set(
    incoming.map((m) => m.clientMessageId).filter(Boolean)
  );
  state.pending = state.pending.filter((p) => !confirmedClientIds.has(p.clientMessageId));

  notify();
}

export function addPendingMessage(pendingMessage) {
  state.pending.push({ ...pendingMessage, status: 'sending' });
  notify();
}

export function resolvePendingMessage(clientMessageId, serverMessage) {
  state.pending = state.pending.filter((p) => p.clientMessageId !== clientMessageId);
  upsertMessages([serverMessage]);
}

export function failPendingMessage(clientMessageId) {
  const target = state.pending.find((p) => p.clientMessageId === clientMessageId);
  if (target) target.status = 'failed';
  notify();
}

export function getPendingMessage(clientMessageId) {
  return state.pending.find((p) => p.clientMessageId === clientMessageId) ?? null;
}
```

```js
import { API_BASE } from './config.js';

export class ChatApiError extends Error {
  constructor(status, code, message) {
    super(message);
    this.name = 'ChatApiError';
    this.status = status;
    this.code = code;
  }
}

/**
 * 모든 요청이 지나가는 단 하나의 통로.
 * 여기서만 오류 형식을 해석하므로, 서버 오류 형식이 바뀌어도 이 함수만 고치면 된다.
 */
async function request(path, { method = 'GET', body, visitorToken } = {}) {
  let response;

  try {
    response = await fetch(`${API_BASE}${path}`, {
      method,
      headers: {
        'Content-Type': 'application/json',
        ...(visitorToken ? { 'X-Visitor-Token': visitorToken } : {})
      },
      body: body ? JSON.stringify(body) : undefined
    });
  } catch (networkError) {
    // fetch 자체가 실패 = 인터넷 끊김, CORS, 서버 다운
    throw new ChatApiError(0, 'NETWORK_ERROR', 'network unreachable');
  }

  if (response.status === 204) return null;

  let payload = null;
  try {
    payload = await response.json();
  } catch {
    payload = null;
  }

  if (!response.ok) {
    const code = payload?.error?.code ?? 'UNKNOWN_ERROR';
    const message = payload?.error?.message ?? `HTTP ${response.status}`;
    throw new ChatApiError(response.status, code, message);
  }

  return payload;
}

export function startChat(payload) {
  return request('/api/public/chat/start', { method: 'POST', body: payload });
}

export function fetchRoom(roomId, visitorToken) {
  return request(`/api/public/chat/${roomId}`, { visitorToken });
}

export function sendMessage(roomId, visitorToken, { text, clientMessageId }) {
  return request(`/api/public/chat/${roomId}/messages`, {
    method: 'POST',
    visitorToken,
    body: { text, clientMessageId }
  });
}
```

```js
}

/**
 * 메시지 목록을 다시 그린다.
 *
 * 스크롤 규칙:
 * 1) 그리기 전에 "지금 맨 아래를 보고 있었나"를 기록한다.
 * 2) 다시 그린 뒤, 보고 있었으면 맨 아래로 따라간다.
 * 3) 아니면 스크롤 위치를 건드리지 않고 '새 메시지' 버튼만 띄운다.
 */
export function renderThread(elements, state) {
  const thread = elements.thread;
  const wasNearBottom = isNearBottom(thread);
  const previousCount = thread.children.length;

  const fragment = document.createDocumentFragment();
  for (const message of state.messages) fragment.appendChild(messageNode(message));
  for (const pending of state.pending) fragment.appendChild(pendingNode(pending));

  thread.replaceChildren(fragment);

  const grew = thread.children.length > previousCount;

  if (wasNearBottom) {
    scrollToBottom(thread);
    elements.newMsgButton.hidden = true;
  } else if (grew) {
    elements.newMsgButton.hidden = false;
  }
}

export function renderState(elements, state) {
  const inChat = state.phase === 'chat';
  elements.formStage.hidden = inChat;
  elements.chatStage.hidden = !inChat;

  // 시작 폼
  const starting = state.phase === 'starting';
  elements.submitButton.disabled = starting;
  elements.submitLabel.textContent = starting ? t('submit.starting') : t('submit.start');
  if (state.errorKey) {
    elements.formStatus.textContent = t(state.errorKey);
    elements.formStatus.classList.add('is-error');
  } else {
    elements.formStatus.textContent = '';
    elements.formStatus.classList.remove('is-error');
  }

  if (!inChat) return;

  // 채팅 화면
  const status = state.room?.status ?? 'bot';
  elements.statusbar.dataset.status = status;
  elements.statusLabel.textContent = t(`status.${status}`);
  elements.reconnecting.hidden = state.connection !== 'reconnecting';

  const closed = status === 'closed';
  elements.composerInput.disabled = closed;
  elements.composerButton.disabled = closed || elements.composerInput.value.trim() === '';
  elements.handoffButton.hidden = closed || status === 'active';

  renderThread(elements, state);
}
```

- [ ] **Step 1: `js/chat/poller.js` 작성**

```js
import { POLL_INTERVAL_MS } from './config.js';
import { ChatApiError, fetchRoom } from './api.js';
import { getSession, setConnection, setRoom, upsertMessages } from './state.js';

let timerId = null;
let inFlight = false;
let handlers = { onError: () => {} };

/**
 * 서버에서 상담방 상태와 메시지를 한 번 가져온다.
 *
 * Phase 4 에서 Socket.IO 로 교체할 때, 이 파일만 socket.js 로 갈아끼우면 된다.
 * widget.js 는 startPolling/stopPolling 이름만 알고 있으므로 영향이 적다.
 */
export async function pollOnce() {
  const session = getSession();
  if (!session || inFlight) return;

  inFlight = true;
  try {
    const room = await fetchRoom(session.roomId, session.visitorToken);
    setRoom({
      status: room.status,
      customerName: room.customerName,
      preferredLanguage: room.preferredLanguage,
      serviceType: room.serviceType
    });
    upsertMessages(room.messages);
    setConnection('ok');
  } catch (error) {
    if (error instanceof ChatApiError && error.code === 'NETWORK_ERROR') {
      // 네트워크 문제는 곧 회복될 수 있으므로 폴링을 멈추지 않는다.
      setConnection('reconnecting');
    } else {
      // 401/403/404 는 세션이 잘못된 것이므로 멈춰야 한다.
      stopPolling();
      handlers.onError(error);
    }
  } finally {
    inFlight = false;
  }
}

export function startPolling({ onError } = {}) {
  stopPolling();
  handlers = { onError: onError ?? (() => {}) };

  void pollOnce();
  timerId = window.setInterval(() => {
    // 브라우저 탭이 백그라운드면 서버를 괴롭히지 않는다.
    if (document.visibilityState === 'hidden') return;
    void pollOnce();
  }, POLL_INTERVAL_MS);

  // 탭으로 돌아오면 즉시 한 번 갱신한다.
  document.addEventListener('visibilitychange', onVisibilityChange);
}

function onVisibilityChange() {
  if (document.visibilityState === 'visible') void pollOnce();
}

export function stopPolling() {
  if (timerId !== null) {
    window.clearInterval(timerId);
    timerId = null;
  }
  document.removeEventListener('visibilitychange', onVisibilityChange);
}
```

`inFlight` 플래그가 중요하다. 이게 없으면 서버 응답이 3초보다 느릴 때 요청이 계속 쌓여서 서버를 과부하시킨다.

- [ ] **Step 1: `js/chat/widget.js` 작성 — 초기화와 세션 복원**

```js
import { ChatApiError, sendMessage, startChat } from './api.js';
import { getLang } from './i18n.js';
import { pollOnce, startPolling, stopPolling } from './poller.js';
import { mountWidget, renderState, scrollToBottom } from './render.js';
import {
  addPendingMessage,
  clearSession,
  failPendingMessage,
  getPendingMessage,
  getSession,
  getState,
  loadSession,
  resolvePendingMessage,
  saveSession,
  setPhase,
  subscribe,
  upsertMessages
} from './state.js';

/* ---------- 페이지 컨텍스트 ---------- */

function detectService() {
  const path = window.location.pathname;
  if (path.includes('/korea-travel')) return 'korea_travel';
  if (path.includes('/stemcell')) return 'stemcell';
  return '';
}

function newClientMessageId() {
  // crypto.randomUUID 는 https 또는 localhost 에서만 쓸 수 있다.
  if (window.crypto?.randomUUID) return window.crypto.randomUUID();
  return `cid-${Date.now()}-${Math.random().toString(16).slice(2)}`;
}

/* ---------- 오류를 i18n 키로 바꾸기 ---------- */

function errorKeyOf(error) {
  if (!(error instanceof ChatApiError)) return 'error.unknown';
  if (error.code === 'NETWORK_ERROR') return 'error.network';
  if (error.status === 401 || error.status === 403 || error.status === 404) return 'error.expired';
  if (error.code === 'ROOM_CLOSED') return 'error.closed';
  return 'error.unknown';
}

/* ---------- 메인 ---------- */

function init() {
  const { elements } = mountWidget({
    defaultService: detectService(),
    defaultLanguage: getLang()
  });

  subscribe((state) => renderState(elements, state));

  bindPanelToggle(elements);
  bindStartForm(elements);
  bindComposer(elements);
  bindThreadActions(elements);

  restoreSession(elements);

  // 첫 렌더
  renderState(elements, getState());
}

/* ---------- 패널 열고 닫기 ---------- */

function bindPanelToggle(elements) {
  elements.toggle.addEventListener('click', () => {
    const isOpen = elements.root.classList.toggle('open');
    elements.toggle.setAttribute('aria-expanded', String(isOpen));
    if (isOpen && getState().phase === 'chat') {
      // 열 때는 항상 최신 메시지를 보여준다.
      scrollToBottom(elements.thread);
      void pollOnce();
    }
  });

  elements.close.addEventListener('click', () => {
    elements.root.classList.remove('open');
    elements.toggle.setAttribute('aria-expanded', 'false');
  });
}

/* ---------- 세션 복원 ---------- */

function restoreSession(elements) {
  const session = loadSession();
  if (!session) return;

  setPhase('chat');
  startPolling({
    onError: (error) => {
      // 저장된 세션이 서버에서 사라졌거나 만료됐다.
      clearSession();
      setPhase('form', errorKeyOf(error));
    }
  });
}

/* ---------- 상담 시작 ---------- */

function bindStartForm(elements) {
  elements.startForm.addEventListener('submit', async (event) => {
    event.preventDefault();

    const data = new FormData(elements.startForm);
    const name = String(data.get('name') ?? '').trim();
    const phone = String(data.get('phone') ?? '').trim();
    const email = String(data.get('email') ?? '').trim();
    const serviceType = String(data.get('serviceType') ?? '').trim();
    const preferredLanguage = String(data.get('preferredLanguage') ?? 'ko');
    const message = String(data.get('message') ?? '').trim();
    const privacyAgreed = data.get('privacyAgreed') === 'on';

    // 화면에서 먼저 막는다. (서버도 다시 검사한다)
    if (!serviceType) return setPhase('form', 'error.service');
    if (!name || !phone) return setPhase('form', 'error.required');
    if (!privacyAgreed) return setPhase('form', 'error.privacy');

    setPhase('starting');

    try {
      const result = await startChat({
        name,
        phone,
        email: email || undefined,
        preferredLanguage,
        serviceType,
        sourcePage: window.location.pathname,
        message: message || undefined,
        privacyAgreed: true
      });

      saveSession({ roomId: result.roomId, visitorToken: result.visitorToken });
      setPhase('chat');
      startPolling({
        onError: (error) => {
          clearSession();
          setPhase('form', errorKeyOf(error));
        }
      });
    } catch (error) {
      setPhase('form', errorKeyOf(error));
    }
  });
}

/* ---------- 메시지 전송 (낙관적 UI) ---------- */

async function submitMessage(text, clientMessageId) {
  const session = getSession();
  if (!session) return;

  try {
    const { message } = await sendMessage(session.roomId, session.visitorToken, {
      text,
      clientMessageId
    });
    resolvePendingMessage(clientMessageId, message);
    // 운영자 답변이 이미 와 있을 수 있으니 바로 한 번 더 확인한다.
    void pollOnce();
  } catch (error) {
    failPendingMessage(clientMessageId);
  }
}

function bindComposer(elements) {
  const input = elements.composerInput;

  input.addEventListener('input', () => {
    // 내용에 맞춰 높이를 늘린다. (최대 높이는 CSS 가 제한한다)
    input.style.height = 'auto';
    input.style.height = `${input.scrollHeight}px`;
    elements.composerButton.disabled = input.value.trim() === '';
  });

  // Enter = 전송, Shift+Enter = 줄바꿈
  input.addEventListener('keydown', (event) => {
    if (event.key === 'Enter' && !event.shiftKey) {
      event.preventDefault();
      elements.composer.requestSubmit();
    }
  });

  elements.composer.addEventListener('submit', (event) => {
    event.preventDefault();
    const text = input.value.trim();
    if (!text) return;

    const clientMessageId = newClientMessageId();
    addPendingMessage({ clientMessageId, text, createdAt: new Date().toISOString() });

    input.value = '';
    input.style.height = 'auto';
    elements.composerButton.disabled = true;
    scrollToBottom(elements.thread);

    void submitMessage(text, clientMessageId);
  });
}

/* ---------- 스레드 내 버튼들 ---------- */

function bindThreadActions(elements) {
  // 새 메시지 버튼
  elements.newMsgButton.addEventListener('click', () => {
    scrollToBottom(elements.thread, 'smooth');
    elements.newMsgButton.hidden = true;
  });

  // 사용자가 직접 맨 아래로 내리면 버튼을 감춘다.
  elements.thread.addEventListener('scroll', () => {
    const distance =
      elements.thread.scrollHeight - elements.thread.scrollTop - elements.thread.clientHeight;
    if (distance <= 100) elements.newMsgButton.hidden = true;
  });

  // 전송 실패 재시도 (이벤트 위임: 말풍선은 계속 새로 그려지므로 개별 등록하면 안 된다)
  elements.thread.addEventListener('click', (event) => {
    const button = event.target.closest('[data-role="retry"]');
    if (!button) return;

    const clientMessageId = button.dataset.clientMessageId;
    const pending = getPendingMessage(clientMessageId);
    if (!pending) return;

    pending.status = 'sending';
    renderState(elements, getState());
    void submitMessage(pending.text, clientMessageId);
  });

  // 담당자 연결 요청
  elements.handoffButton.addEventListener('click', async () => {
    const session = getSession();
    if (!session) return;

    const clientMessageId = newClientMessageId();
    const text = getLang() === 'ja' ? '担当者と相談したいです。' : '담당자와 상담하고 싶습니다.';
    addPendingMessage({ clientMessageId, text, createdAt: new Date().toISOString() });
    await submitMessage(text, clientMessageId);
  });

  // 새 상담 시작
  elements.newChatButton.addEventListener('click', () => {
    stopPolling();
    clearSession();
  });
}

/* ---------- 실행 ---------- */

if (document.readyState === 'loading') {
  document.addEventListener('DOMContentLoaded', init);
} else {
  init();
}
```

`bindThreadActions`에서 **이벤트 위임**을 쓰는 이유가 중요하다. `renderThread`가 매번 말풍선 DOM을 새로 만들기 때문에, 개별 버튼에 `addEventListener`를 걸면 다시 그리는 순간 사라진다. 부모(`thread`)에 한 번만 걸고 `event.target.closest()`로 어느 버튼인지 판별하면 된다.

```ts
  await page.goto('/korea-travel/');
  await page.locator('.consult-chat-toggle').click();
  await expect(page.locator('.consult-chat')).toHaveClass(/open/);
}

async function fillStartForm(page: Page, overrides: { privacy?: boolean } = {}) {
  await page.selectOption('select[name="serviceType"]', 'korea_travel');
  await page.fill('input[name="name"]', 'E2E 고객');
  await page.fill('input[name="phone"]', '010-1234-5678');
  await page.fill('textarea[name="message"]', '来月、母と2人で韓国に行きたいです。');
  if (overrides.privacy !== false) {
    await page.check('input[name="privacyAgreed"]');
  }
}

test.describe('고객 채팅 위젯', () => {
  test.beforeEach(async ({ page }) => {
    // 이전 테스트의 세션이 남아 있으면 폼이 안 보인다.
    await page.goto('/korea-travel/');
    await page.evaluate(() => window.localStorage.clear());
  });

  test('상담 버튼을 누르면 위젯이 열린다', async ({ page }) => {
    await openWidget(page);

    await expect(page.locator('.consult-chat-form')).toBeVisible();
    await expect(page.locator('input[name="name"]')).toBeVisible();
  });

  test('개인정보 동의 없이는 상담이 시작되지 않는다', async ({ page }) => {
    await openWidget(page);
    await fillStartForm(page, { privacy: false });

    await page.locator('.consult-chat-submit').click();

    await expect(page.locator('.consult-chat-status')).toContainText('동의');
    // 채팅 화면으로 넘어가지 않았다.
    await expect(page.locator('.consult-chat-thread')).toBeHidden();
  });

  test('이름과 연락처가 없으면 오류가 표시된다', async ({ page }) => {
    await openWidget(page);
    await page.selectOption('select[name="serviceType"]', 'korea_travel');
    await page.check('input[name="privacyAgreed"]');

    await page.locator('.consult-chat-submit').click();

    await expect(page.locator('.consult-chat-status')).toContainText('연락처');
  });

  test('상담을 시작하면 첫 문의가 말풍선으로 보인다', async ({ page }) => {
    await openWidget(page);
    await fillStartForm(page);

    await page.locator('.consult-chat-submit').click();

    await expect(page.locator('.consult-chat-thread')).toBeVisible();
    await expect(page.locator('.consult-chat-msg[data-sender="customer"]')).toContainText(
      '来月、母と2人で韓国に行きたいです。'
    );
    await expect(page.locator('[data-role="status-label"]')).toContainText('AI 상담 중');
  });

  test('메시지를 보내면 화면에 즉시 나타난다', async ({ page }) => {
    await openWidget(page);
    await fillStartForm(page);
    await page.locator('.consult-chat-submit').click();
    await expect(page.locator('.consult-chat-thread')).toBeVisible();

    await page.fill('.consult-chat-composer textarea', 'ホテルの予約もお願いできますか。');
    await page.locator('.consult-chat-composer button').click();

    await expect(
      page.locator('.consult-chat-msg', { hasText: 'ホテルの予約もお願いできますか。' })
    ).toBeVisible();
  });

  test('새로고침해도 대화가 유지된다', async ({ page }) => {
    await openWidget(page);
    await fillStartForm(page);
    await page.locator('.consult-chat-submit').click();
    await expect(page.locator('.consult-chat-thread')).toBeVisible();

    await page.reload();
    await page.locator('.consult-chat-toggle').click();

    await expect(page.locator('.consult-chat-thread')).toBeVisible();
    await expect(page.locator('.consult-chat-msg[data-sender="customer"]')).toContainText(
      '来月、母と2人で韓国に行きたいです。'
    );
  });

  test('서버 오류가 나면 안내 문구를 보여준다', async ({ page }) => {
    // 상담 시작 요청만 500 으로 가로챈다.
    await page.route(`${API}/api/public/chat/start`, (route) =>
      route.fulfill({
        status: 500,
        contentType: 'application/json',
        body: JSON.stringify({ error: { code: 'INTERNAL_ERROR', message: '서버 오류' } })
      })
    );

    await openWidget(page);
    await fillStartForm(page);
    await page.locator('.consult-chat-submit').click();

    await expect(page.locator('.consult-chat-status')).toContainText('문제가 발생했습니다');
  });

  test('전송에 실패하면 재시도 버튼이 나온다', async ({ page }) => {
    await openWidget(page);
    await fillStartForm(page);
    await page.locator('.consult-chat-submit').click();
    await expect(page.locator('.consult-chat-thread')).toBeVisible();

    // 이제부터 메시지 전송만 실패시킨다.
    await page.route('**/api/public/chat/*/messages', (route) => route.abort());

    await page.fill('.consult-chat-composer textarea', '실패할 메시지');
    await page.locator('.consult-chat-composer button').click();

    await expect(page.locator('.consult-chat-msg[data-state="failed"]')).toBeVisible();
    await expect(page.locator('[data-role="retry"]')).toBeVisible();
  });

  test('예전 메시지를 읽는 중에는 화면이 아래로 튀지 않는다', async ({ page }) => {
    await openWidget(page);
    await fillStartForm(page);
    await page.locator('.consult-chat-submit').click();
    await expect(page.locator('.consult-chat-thread')).toBeVisible();

    // 메시지를 충분히 쌓는다.
    for (let i = 0; i < 15; i += 1) {
      await page.fill('.consult-chat-composer textarea', `메시지 ${i}`);
      await page.locator('.consult-chat-composer button').click();
      await expect(page.locator('.consult-chat-msg', { hasText: `메시지 ${i}` })).toBeVisible();
    }

    // 맨 위로 올린다.
    await page.locator('.consult-chat-thread').evaluate((el) => {
      el.scrollTop = 0;
    });
    const before = await page.locator('.consult-chat-thread').evaluate((el) => el.scrollTop);

    // 새 메시지가 도착할 시간을 준다 (폴링 주기 3초 + 여유).
    await page.waitForTimeout(4000);
    const after = await page.locator('.consult-chat-thread').evaluate((el) => el.scrollTop);

    expect(after).toBe(before);
  });

  test('루트 페이지에서는 서비스 선택 링크가 보인다', async ({ page }) => {
    await page.goto('/');
    await page.evaluate(() => window.localStorage.clear());
    await page.reload();
    await page.locator('.consult-chat-toggle').click();

    // 루트에도 동일한 상담 폼이 뜬다. (서비스 분야를 직접 고른다)
    await expect(page.locator('select[name="serviceType"]')).toBeVisible();
  });
});
```

## 초보자가 자주 막히는 지점

**"Cannot use import statement outside a module"**
`<script>` 태그에 `type="module"` 을 안 붙였다.

**"CORS policy 오류가 난다"**
`.env`의 `WEBSITE_ORIGIN` 이 `http://localhost:8080` 인지 확인하고 API 서버를 재시작한다. `file://` 로 HTML을 직접 열면 origin이 `null` 이라 무조건 막힌다. 반드시 `docker compose up -d web` 으로 8080에서 연다.

**"메시지가 두 번 보인다"**
낙관적 UI로 띄운 pending 말풍선이 서버 메시지로 교체되지 않았다. `clientMessageId`를 서버에 보내고 있는지, 서버 응답의 `clientMessageId`가 같은 값인지 확인한다.

**"crypto.randomUUID is not a function"**
`http://`(https 아님) + `localhost`가 아닌 주소에서는 쓸 수 없다. `newClientMessageId()`의 fallback이 동작하는지 확인한다.

**"새로고침하면 대화가 사라진다"**
`localStorage`에 저장이 안 됐거나, 사파리 프라이빗 모드다. 콘솔에서 `localStorage.getItem('scj-chat-session')`을 확인한다.

**"위로 스크롤했는데도 화면이 내려간다"**
`renderThread`에서 `wasNearBottom`을 **DOM을 바꾸기 전에** 계산해야 한다. 바꾼 뒤에 계산하면 `scrollHeight`가 이미 늘어나 있어서 항상 `false`가 나오거나, 반대로 항상 스크롤된다.
