## 프로젝트 개요

StemCareJapan은 두 가지 서비스를 분리해 안내하는 정적 홈페이지이며, 여기에 실시간 상담 채팅
시스템이 더해진 구성입니다.

1. **한국 고객 대상 일본 재생의료 상담 컨시어지**
   - 한국에서 일본 현지 의료기관 상담을 검토하는 고객을 위한 상담, 예약, 통역, 이동, 숙박, 체류 지원 서비스입니다.
   - StemCareJapan은 의료행위를 직접 제공하지 않으며, 치료 가능 여부와 의학적 판단은 현지 의료진 상담 후 결정됩니다.

2. **일본 고객 대상 한국 체류 컨시어지**
   - 일본에서 한국을 방문하는 고객을 위한 단순 픽업, 일반관광, 비즈니스 방문, 미용관광, 공항 픽업, 전용차량, 호텔, 통역, 일정 조율 서비스입니다.

3. **상담 채팅 시스템** (`apps/api`, `apps/admin`, `js/chat/`)
   - 두 서비스 페이지 어디서든 우측 하단 위젯으로 실시간 상담을 시작할 수 있습니다. AI가 먼저
     응대하고, 필요하면 담당 운영자에게 자동으로 연결됩니다.
   - 정적 홈페이지와는 별도의 애플리케이션(Node.js API 서버 + Next.js 관리자 화면)으로
     동작합니다. 자세한 내용은 [상담 채팅 시스템](#상담-채팅-시스템-phase-06) 섹션 참고.

루트 화면에서 방문 목적에 맞는 서비스를 선택한 뒤 각 상세 페이지로 이동합니다.

| 경로 | 대상 | 기본 언어 | 주요 내용 |
|------|------|-----------|-----------|
| `/` | 전체 방문자 | 한국어 | 서비스 선택 게이트웨이 |
| `/stemcell/` | 한국 -> 일본 재생의료 상담 희망자 | 한국어 | 일본 병원 상담 준비, 통역, 이동, 숙박, 체류, 사후 안내 |
| `/korea-travel/` | 일본 -> 한국 방문 희망자 | 일본어 | 단순 픽업, 일반관광, 비즈니스, 미용관광, 공항 픽업, 차량, 호텔, 통역 |

## 현재 페이지 구성

### 1. 서비스 선택 페이지 (`/`)

- StemCareJapan 브랜드 게이트웨이
- 한국 고객용 일본 재생의료 상담 컨시어지 진입
- 일본 고객용 한국 체류 컨시어지 진입
- 상담 채팅 위젯 (`/`, `/stemcell/`, `/korea-travel/` 모두에서 제공)

### 2. 일본 재생의료 상담 컨시어지 (`/stemcell/`)

- **Hero**: 일본 재생의료 상담 컨시어지 포지션 및 상담 CTA
- **About**: 일본 재생의료 제도와 StemCareJapan의 컨시어지 역할 안내
- **Medical Notice**: 의료행위 직접 제공이 아닌 상담·예약·통역·이동·체류 지원임을 명시
- **Services**: 국내 에스코트, 일본 공항 에스코트, 숙박, 병원 상담 지원, 관광, 24시간 서포트
- **Process**: 상담 신청부터 맞춤 플랜, 출국 준비, 현지 일정, 귀국 후 안내까지 단계별 설명
- **Treatment**: 자가줄기세포, 동종줄기세포, 엑소좀 등 상담 전 확인해야 할 치료 유형 안내
- **상담 요청 분야**: 신경계, 심혈관, 근골격계, 내분비, 항노화·미용, 호흡기·면역 등 문의가 많은 분야
- **병원 상담 후보**: 오사카, 도쿄, 후쿠오카권 상담 후보와 확인 필요 정보
- **Tourism**: 도쿄, 오사카, 후쿠오카, 교토 체류·관광 정보
- **Cases**: 실제 치료 후기 대신 상담 사례 형식으로 리스크를 낮춘 콘텐츠
- **FAQ**: 치료·비용·비자·통역·동행 관련 질문
- **Contact**: 일본 병원 상담 가능 여부 문의 폼

### 3. 한국 체류 컨시어지 (`/korea-travel/`)

- **Hero**: 일반관광, 비즈니스 방문, 미용관광을 포괄하는 한국 체류 컨시어지 포지션
- **기본 수배**: 공항-호텔 픽업, 호텔-관광지 픽업, 전용차량, 목적별 플랜, 호텔, 관광·상담·쇼핑, 24시간 일본어 지원
- **차량 안내**: Genesis G90, Hyundai STARIA 차량 이미지와 이용 상황 안내
- **목적별 한국 체류 서비스**
  - 일반관광: 서울 대표 관광, 미식·쇼핑, 지방·테마 여행
  - 비즈니스: 기업·전시회 방문, 통역·어텐드, VIP 이동·회식 수배
  - 미용관광: 클리닉 상담 조율, K뷰티 체험, 시술 전후 체류 설계
- **조합 예시**: 첫 서울 3일, 비즈니스 2박 3일, 미용 상담+관광 4일, 가족·친구 그룹, 지방 순회, 완전 맞춤 체류
- **서비스 범위**: 공항-호텔, 호텔-관광지 단순 픽업을 포함한 수배 가능 항목과 별도 확인이 필요한 비용 구분
- **목적별 샘플 일정**: 일반관광, 비즈니스, 미용관광 일정 예시
- **상담 준비 정보**: 방문일, 인원, 희망 지역, 통역·차량 필요 시간, 예산 등
- **미용관광 고지**: 의료행위 직접 제공이 아닌 클리닉 상담 예약, 통역, 이동, 체류 지원임을 명시
- **Process**: 상담, 체류 플랜 설계, 예약·수배, 한국 도착, 체류 중 지원
- **Plans**: 한국 일반관광, 비즈니스 방문 지원, 미용관광 컨시어지
- **FAQ**: 언어, 단독 서비스 의뢰, 비용 기준, 비자, 상담 시점, 일정 변경·트러블 대응
- **Contact**: 일정·견적 상담 폼

## 다국어 지원 방식

### `stemcell/`

- `js/main.js`의 `i18nData` 객체 사용
- `data-i18n`, `data-i18n-html` 속성으로 문구 교체
- KO, JA, EN 전환 버튼 제공
- 기본 언어는 한국어

### `korea-travel/`

- HTML 요소의 `data-ja`, `data-ko` 속성 사용
- `js/travel.js`(전용 스크립트, `main.js`와 별개)의 언어 전환 로직으로 텍스트, 옵션,
  placeholder 교체
- JA, KO 전환 버튼 제공
- `data-default-lang="ja"`로 일본어 우선 표시

### 상담 채팅 위젯 (`js/chat/`)

- 위젯 문구는 `js/chat/i18n.js`의 한국어/일본어 사전과 `data-i18n` 속성으로 표시합니다. 메인
  사이트의 `i18nData`(`js/main.js`)와는 별개의 사전입니다.
- 위젯은 `<html lang>`을 MutationObserver로 감시하다가, 페이지의 언어 전환 버튼이 언어를 바꾸면
  위젯도 같은 언어로 다시 그립니다 — 페이지와 위젯의 언어가 따로 노는 일이 없습니다.
- `guide/index.html`(고객용 이용 가이드)도 같은 방식으로 자체 KO/JA 토글을 제공합니다.

## 정적 문의 폼 데이터 (`#contact`, 상담 채팅과 별개)

두 상세 페이지의 정적 상담 폼(성함·연령·연락처·질환/방문목적·희망 패키지·문의 내용)은 현재
프론트엔드에서 데이터를 수집한 뒤 `tables/inquiries`로 `POST`를 시도합니다. **우측 하단의 실시간
상담 채팅 위젯과는 별개의 폼**이며, 실제 상담 데이터를 저장·처리하는 백엔드는 아래 [상담 채팅
시스템](#상담-채팅-시스템-phase-06) 쪽(`apps/api` + PostgreSQL)에만 연결되어 있습니다.

이 정적 폼은 백엔드가 없거나 API가 실패해도 사용자에게는 완료 모달을 보여주는 구조입니다. 실제
운영 전에는 백엔드 연동, 관리자 화면, 개인정보 처리 동의, 저장 정책 연동이 필요합니다 — 이
폼을 상담 채팅 시스템으로 통합할지, 별도로 유지할지는 별도 결정이 필요합니다.

### 공통 전송 필드

| 필드 | 설명 |
|------|------|
| `name` | 이름 |
| `age` | 연령 또는 인원 |
| `phone` | 연락처 |
| `email` | 이메일 |
| `disease` | 주요 증상/질환 또는 방문 목적 |
| `package` | 관심 패키지 또는 희망 플랜 |
| `message` | 문의 내용 |
| `submitted_at` | 제출 일시 |

## 운영 및 콘텐츠 주의사항

### 의료·미용 관련 표현

- StemCareJapan은 의료행위를 직접 제공하지 않는 컨시어지 서비스로 표현합니다.
- 치료 효과, 완치, 개선 보장, 안전 보장 등 단정적 표현은 사용하지 않습니다.
- 고객 후기는 치료 결과를 암시하는 문장보다 상담 사례, 준비 과정, 동행 지원 중심으로 작성합니다.
- 미용관광도 시술 추천이 아니라 상담 예약, 통역, 이동, 체류 지원으로 표현합니다.

### 병원·클리닉 정보

- 병원명, 제휴 여부, 인증, 가능 진료, 통역 여부는 공개 전 실제 근거 확인이 필요합니다.
- 공식 홈페이지 링크, 사진·로고 사용 권리, 제휴 문구 사용 가능 여부를 확인해야 합니다.

### 개인정보

- 정적 상담 폼과 채팅 위젯 모두 이름, 연락처, 건강 또는 방문 목적 정보를 받을 수 있습니다.
- **상담 채팅 시스템**은 개인정보 보관 기간이 코드 상수로 구현되어 있습니다 — 상담 종료 180일
  후 연락처 비식별화, 365일 후 대화 내용 삭제 (자세한 내용은 [상담 채팅
  시스템](#상담-채팅-시스템-phase-06) 섹션과 운영 가이드 참고). 서버 로그에도 이름·연락처·
  상담 본문이 남지 않도록 마스킹되어 있습니다.
- 반면 정적 상담 폼(`#contact`)은 아직 백엔드가 없어 별도의 저장·보관 정책이 없습니다. 실제
  운영 전 이 폼에 대한 개인정보처리방침, 민감정보 수집 여부, 제3자 제공 여부, 보관 기간 안내가
  필요합니다.

### 이미지 권리

- `korea-travel/` 페이지의 일부 차량·서울 이미지는 출처가 푸터에 표시되어 있습니다.
- 공개 또는 상업 운영 전 이미지 사용 권리 확인이 필요합니다.

## 로컬 실행

### 정적 홈페이지만 볼 때

Docker(권장)로 실행하면 nginx 컨테이너가 파일 변경을 바로 반영합니다.

```bash
docker compose up -d web
```

브라우저에서 `http://localhost:8080`으로 접속합니다. Docker 없이 보려면:

```bash
python3 -m http.server 8080
# 또는
npx serve .
```

### 상담 채팅 위젯까지 함께 볼 때

정적 홈페이지의 상담 채팅 위젯이 실제로 동작하려면 API 서버(`apps/api`)가 함께 떠 있어야
합니다. 최초 설정과 매일 개발 시 실행 순서는 [`README-chat.md`](README-chat.md)를 참고하세요.

```bash
npm install
cp .env.example .env
npm run build -w packages/shared
docker compose up -d postgres
npm run db:migrate:deploy -w apps/api
npm run db:seed -w apps/api

docker compose up -d web   # 정적 홈페이지 (8080)
npm run dev:api            # API 서버 (4000)
npm run dev:admin          # 운영자 관리자 화면 (3100)
```

## 상담 채팅 시스템 (Phase 0~6)

정적 홈페이지와 별개로, 실시간 상담 채팅을 위한 애플리케이션이 같은 저장소 안에서
npm workspace로 관리됩니다.

| 구성 요소 | 경로 | 역할 |
|---|---|---|
| 채팅 위젯 | `js/chat/` | 홈페이지에 삽입되는 실시간 채팅 UI (ES 모듈, 빌드 도구 없음) |
| API 서버 | `apps/api` | 채팅방·메시지 저장, AI 응답, 번역, 인증, 운영 지표 (Express + Socket.IO + Prisma) |
| 관리자 화면 | `apps/admin` | 운영자가 로그인해 상담을 처리하는 화면 (Next.js) |
| 공용 타입 | `packages/shared` | API·관리자 화면이 함께 쓰는 타입·상수 |

**구현된 주요 기능**: AI 1차 응대와 운영자 자동 전환, Socket.IO 실시간 통신(연결 실패 시 폴링
자동 대체), 한국어·일본어 자동 번역과 운영자 번역 미리보기, 상담 이력·내부 메모, 개인정보
보관 정책(비식별화·삭제 자동화), 보안 헤더·요청 제한·구조화 로그, 운영 지표 대시보드, 상담
만족도 평가, Docker/Nginx 배포 구성과 백업·복구 스크립트, Playwright E2E까지 로컬 환경에서
구현·검증을 완료했습니다.
