# 스템케어재팬 (StemCareJapan) 홈페이지

## 프로젝트 개요

StemCareJapan은 두 가지 서비스를 분리해 안내하는 정적 홈페이지입니다.

1. **한국 고객 대상 일본 재생의료 상담 컨시어지**
   - 한국에서 일본 현지 의료기관 상담을 검토하는 고객을 위한 상담, 예약, 통역, 이동, 숙박, 체류 지원 서비스입니다.
   - StemCareJapan은 의료행위를 직접 제공하지 않으며, 치료 가능 여부와 의학적 판단은 현지 의료진 상담 후 결정됩니다.

2. **일본 고객 대상 한국 체류 컨시어지**
   - 일본에서 한국을 방문하는 고객을 위한 일반관광, 비즈니스 방문, 미용관광, 공항 픽업, 전용차량, 호텔, 통역, 일정 조율 서비스입니다.

루트 화면에서 방문 목적에 맞는 서비스를 선택한 뒤 각 상세 페이지로 이동합니다.

| 경로 | 대상 | 기본 언어 | 주요 내용 |
|------|------|-----------|-----------|
| `/` | 전체 방문자 | 한국어 | 서비스 선택 게이트웨이 |
| `/stemcell/` | 한국 -> 일본 재생의료 상담 희망자 | 한국어 | 일본 병원 상담 준비, 통역, 이동, 숙박, 체류, 사후 안내 |
| `/korea-travel/` | 일본 -> 한국 방문 희망자 | 일본어 | 일반관광, 비즈니스, 미용관광, 공항 픽업, 차량, 호텔, 통역 |

## 현재 페이지 구성

### 1. 서비스 선택 페이지 (`/`)

- StemCareJapan 브랜드 게이트웨이
- 한국 고객용 일본 재생의료 상담 컨시어지 진입
- 일본 고객용 한국 체류 컨시어지 진입
- 상담 채팅 위젯

### 2. 일본 재생의료 상담 컨시어지 (`/stemcell/`)

- **Hero**: 일본 재생의료 상담 컨시어지 포지션 및 상담 CTA
- **About**: 일본 재생의료 제도와 StemCareJapan의 컨시어지 역할 안내
- **Medical Notice**: 의료행위 직접 제공이 아닌 상담·예약·통역·이동·체류 지원임을 명시
- **Services**: 국내 에스코트, 일본 공항 에스코트, 숙박, 병원 상담 지원, 관광, 24시간 서포트
- **Process**: 상담 신청부터 맞춤 플랜, 출국 준비, 현지 일정, 귀국 후 안내까지 단계별 설명
- **Treatment**: 자가줄기세포, 동종줄기세포, 엑소좀 등 상담 전 확인해야 할 치료 유형 안내
- **상담 요청 분야**: 신경계, 심혈관, 근골격계, 내분비, 항노화·미용, 호흡기·면역 등 문의가 많은 분야
- **병원 상담 후보**: 오사카, 도쿄, 후쿠오카권 상담 후보와 확인 필요 정보
- **Tourism**: 도쿄, 오사카, 후쿠오카, 교토 체류·관광 정보
- **Cases**: 실제 치료 후기 대신 상담 사례 형식으로 리스크를 낮춘 콘텐츠
- **FAQ**: 치료·비용·비자·통역·동행 관련 질문
- **Contact**: 일본 병원 상담 가능 여부 문의 폼

### 3. 한국 체류 컨시어지 (`/korea-travel/`)

- **Hero**: 일반관광, 비즈니스 방문, 미용관광을 포괄하는 한국 체류 컨시어지 포지션
- **기본 수배**: 공항 픽업, 전용차량, 목적별 플랜, 호텔, 관광·상담·쇼핑, 24시간 일본어 지원
- **차량 안내**: Genesis G90, Hyundai STARIA 차량 이미지와 이용 상황 안내
- **목적별 한국 체류 서비스**
  - 일반관광: 서울 대표 관광, 미식·쇼핑, 지방·테마 여행
  - 비즈니스: 기업·전시회 방문, 통역·어텐드, VIP 이동·회식 수배
  - 미용관광: 클리닉 상담 조율, K뷰티 체험, 시술 전후 체류 설계
- **조합 예시**: 첫 서울 3일, 비즈니스 2박 3일, 미용 상담+관광 4일, 가족·친구 그룹, 지방 순회, 완전 맞춤 체류
- **서비스 범위**: 수배 가능한 항목과 별도 확인이 필요한 비용 구분
- **목적별 샘플 일정**: 일반관광, 비즈니스, 미용관광 일정 예시
- **상담 준비 정보**: 방문일, 인원, 희망 지역, 통역·차량 필요 시간, 예산 등
- **미용관광 고지**: 의료행위 직접 제공이 아닌 클리닉 상담 예약, 통역, 이동, 체류 지원임을 명시
- **Process**: 상담, 체류 플랜 설계, 예약·수배, 한국 도착, 체류 중 지원
- **Plans**: 한국 일반관광, 비즈니스 방문 지원, 미용관광 컨시어지
- **FAQ**: 언어, 단독 서비스 의뢰, 비용 기준, 비자, 상담 시점, 일정 변경·트러블 대응
- **Contact**: 일정·견적 상담 폼

## 다국어 지원 방식

### `stemcell/`

- `js/main.js`의 `i18nData` 객체 사용
- `data-i18n`, `data-i18n-html` 속성으로 문구 교체
- KO, JA, EN 전환 버튼 제공
- 기본 언어는 한국어

### `korea-travel/`

- HTML 요소의 `data-ja`, `data-ko` 속성 사용
- `main.js`의 공통 언어 전환 로직으로 텍스트, 옵션, placeholder 교체
- JA, KO 전환 버튼 제공
- `data-default-lang="ja"`로 일본어 우선 표시

## 상담 폼 데이터

두 상세 페이지의 상담 폼은 현재 프론트엔드에서 데이터를 수집한 뒤 `tables/inquiries`로 `POST`를 시도합니다.

백엔드가 없거나 API가 실패해도 사용자에게는 완료 모달을 보여주는 구조입니다. 실제 운영 전에는 백엔드, 관리자 화면, 개인정보 처리 동의, 저장 정책 연동이 필요합니다.

### 공통 전송 필드

| 필드 | 설명 |
|------|------|
| `name` | 이름 |
| `age` | 연령 또는 인원 |
| `phone` | 연락처 |
| `email` | 이메일 |
| `disease` | 주요 증상/질환 또는 방문 목적 |
| `package` | 관심 패키지 또는 희망 플랜 |
| `message` | 문의 내용 |
| `submitted_at` | 제출 일시 |

## 운영 및 콘텐츠 주의사항

### 의료·미용 관련 표현

- StemCareJapan은 의료행위를 직접 제공하지 않는 컨시어지 서비스로 표현합니다.
- 치료 효과, 완치, 개선 보장, 안전 보장 등 단정적 표현은 사용하지 않습니다.
- 고객 후기는 치료 결과를 암시하는 문장보다 상담 사례, 준비 과정, 동행 지원 중심으로 작성합니다.
- 미용관광도 시술 추천이 아니라 상담 예약, 통역, 이동, 체류 지원으로 표현합니다.

### 병원·클리닉 정보

- 병원명, 제휴 여부, 인증, 가능 진료, 통역 여부는 공개 전 실제 근거 확인이 필요합니다.
- 공식 홈페이지 링크, 사진·로고 사용 권리, 제휴 문구 사용 가능 여부를 확인해야 합니다.

### 개인정보

- 상담 폼과 채팅 위젯에서 이름, 연락처, 건강 또는 방문 목적 정보를 받을 수 있습니다.
- 실제 운영 전 개인정보처리방침, 민감정보 수집 여부, 제3자 제공 여부, 보관 기간 안내가 필요합니다.

### 이미지 권리

- `korea-travel/` 페이지의 일부 차량·서울 이미지는 출처가 푸터에 표시되어 있습니다.
- 공개 또는 상업 운영 전 이미지 사용 권리 확인이 필요합니다.
